# Cosmetic Gear — Issues & Suggestions

Welcome to the official issue tracker for **Cosmetic Gear**, a Minecraft Forge mod.

This repository is dedicated to bug reports, crash reports, compatibility problems, and feature suggestions.

## Report an Issue

**[Click here to submit a report](https://github.com/yasindemircw00-web/CosmeticGear-Issues/issues/new/choose)**

Please select the appropriate category:

- **Bug Report** — Report bugs or unexpected mod behavior.
- **Crash Report** — Report Minecraft crashes potentially related to Cosmetic Gear.
- **Compatibility Report** — Report conflicts with Curios or other Minecraft mods.
- **Suggestion** — Suggest improvements or new features.
- **Other** — Submit questions or reports that do not fit the categories above.

## Before Submitting

Please:

1. Check existing issues to avoid duplicates.
2. Include your Cosmetic Gear version.
3. Provide your Minecraft and Forge versions.
4. Explain how to reproduce the problem.
5. Attach screenshots or relevant logs when available.

## API Documentation

Cosmetic Gear provides a public API for other Minecraft Forge mods to integrate with its cosmetic equipment and visibility systems.

The API supports server-side equipment management, cosmetic and real armor visibility controls, Forge events, and client-side rendering integration.

**[View the Cosmetic Gear API Documentation](https://github.com/yasindemircw00-web/CosmeticGear-Issues/blob/main/API.md)**
